## 范围

沿用 DSH 现有菜单挂载与 `--dsw-*` 主题变量，完成订阅列表、搜索筛选、新建订阅、详情抽屉、暂停、恢复、停止确认和通知凭证占位页。所有数据为专用演示数据，仅保存在组件内存，重新挂载或刷新后重置，不访问数据库或外部会话。

订阅状态、任务结果、检查失败和通知投递结果分别展示。poll 必选接收会话；push 可选择通知时新建。抽屉支持 Escape、焦点圈定和焦点恢复。窄屏保留横向滚动列表。

## T6 列表样式调整

按截图反馈增加开始时间列（北京时间），将最近检查和会话消息拆为两列；未生成消息时显示破折号，悬停说明。Agent 名称与订阅类型使用不同字重和轻量标签，结束原因按结果区分颜色；保留订阅状态与任务结果的语义差异。筛选下拉框自绘指示箭头并留出右侧空间，行内容垂直居中，窄屏列表仍采用横向滚动。新建演示订阅使用实际创建时间。已通过构建并在浏览器预览核对新增列及样式。

列表进一步调整为 Agent 与类型同行、订阅状态与结束原因同行，保留标签间距和结果颜色；窄屏使用表格横向滚动。

按后续反馈，列表订阅状态列只保留状态标签，不再追加任务完成、到期结束等原因；完整结束原因仍在详情中展示。

## T6 新建表单范围调整

新建入口只提供主动订阅（poll）；已有演示记录中的 push 仍用于展示历史状态。动作默认汇报，可选择自定义动作并填写说明，创建后在详情查看。接收会话默认新建，也可选择已有会话。所有配置仅在页面内存中保存，不执行动作。

这更新了原页面的 poll 必选已有接收会话约束；后端现有 poll 仍需要真实 DSH 会话 ID，接入时必须先创建接收会话，再调用订阅服务。动作字段尚无服务层持久化和执行契约，预留 TODO，不能将本次界面调整视为后端已支持。
