# T2.4、T2.5、T3.1、T4、T6：M2 实施与验收

日期：2026-11-11（Asia/Shanghai）。分支：`codex/m2-subscriptions`。本次改动在独立 worktree 完成。

## 已实现

- 插件入口创建 Claude/Codex Adapter、注册表、Scheduler、订阅/检查/通知服务；注入 schedule、sessionController、sessions、sessionQuery、connection。启动先恢复中断投递，再对账订阅提醒；后台每 30 秒重试对账及通知投递。
- 独立 `runtime-lock.sqlite` 用 SQLite `BEGIN EXCLUSIVE` 保证同一数据目录只有一个执行实例；进程退出后由 OS 释放锁，恢复前不猜测旧实例是否仍在发送。
- 检查器按订阅加锁，跳过未到期、暂停、结束状态；处理新消息、busy、关闭、最长存活、完成/失败轮次、连续检查失败。异步快照后重读状态和截止时间，避免覆盖用户停止/暂停/查阅操作。
- cursor 中保留原始订阅基线，另以 observed 保存最近观察位置。顺延后仍可判定基线之后的已结束轮次，避免旧内容误报完成或遗漏完成结果。
- Snapshot.check_error 区分实际查询失败和正常的实时状态未知。Claude 状态命令失败进入连续失败计数；Codex daemon 的正常 unknown 不等于空闲或完成，也不计为读取失败。
- 通知登记和 poll 终态沿用 SQLite 事务与唯一约束。投递最多三次；followup 后 flush 成功才记持久送达。超时/异常保留 unknown，按稳定消息 ID 核对 inbox splice 或 user/message；无法核对时不重发。
- 工具：relay_ping、relay_list_sessions、relay_subscribe、relay_list、relay_stop、relay_check。订阅默认绑定调用工具的 DSH 会话；显式目标仍按 ID 路由。提醒创建失败返回 schedule_ready=false，不声称检查已就绪。
- 认证 RPC 共用同一服务层：agents、sessions、dsh_sessions、subscribe、list、get、pause、resume、stop、check，挂在 `/api/agent-relay/<操作>`。通过 DSH connection 的 owner 认证桥接，不新开业务 HTTP 端口。
- 看板支持 Agent/类型/状态筛选、分页、检查与投递错误、结果摘要、暂停/恢复/停止/检查、打开接收会话；新建订阅可选择外部会话、接收 DSH 会话与有效期。Codex 的只读能力与限制有文字提示。
- 卸载先拒绝新操作、移除 RPC/清理定时器，等待在途服务及通知完成后关闭存储并释放执行锁。前端类型检查已加入 typecheck。

## 配置与使用

依赖 DSH 0.2.1-rc.2 已存在的官方服务，沿用原 npm 包挂载方式。默认有效期与检查周期 3600 秒，最长存活 86400 秒，连续失败阈值 3。页面有效期单位为分钟，最少一分钟。`relay_check` 和页面“检查一次”遵守截止时间，未到期时返回跳过，不提前结束订阅。

```sh
rtk npm ci --cache ./.npm-cache
rtk npm run typecheck
rtk npm test
rtk proxy node test/smoke/m2-smoke.js
```

真实冒烟依赖本机 DSH 和 Claude CLI，会创建专用 Claude 会话并产生少量费用。脚本创建临时 DSH_HOME，只把专用会话记录以符号链接方式挂载到测试 Claude 目录，不修改外部历史。实际目录在结束时输出，供人工核对。测试启动器依赖 DSH 0.2.1-rc.2 的内部结构，版本升级需重新核实；产品运行入口不依赖该内部启动器。

## 边界和剩余限制

- 送达表示消息已经进入 DSH 收件箱并持久化、已请求唤醒，不表示模型已经执行完成。接收会话缺少有效模型凭据时，通知仍可能持久送达，但 DSH 后续处理会失败。
- 订阅检查由模型执行，实际延迟及可靠性取决于所选模型正确调用工具。确定性测试模型用于验证连接机制，不代替真实模型的行为保证。
- M2 入口仅创建 poll。后续 M3/M4 已补充消息转发、`relay_send`、push HTTP、共享 token、通知会话创建和通用 Agent Relay Skill，具体实现见对应 M3/M4 文档。
- T4 已提供独立修改周期和有效期的认证 RPC，页面可暂停/恢复/停止并展示修改后的配置。
- 原有 T6.3 工作区分组前置保留；已有接收会话不会被迁移到 Agent Relay 分组。
- Codex 已注册现有只读 Adapter，本轮不把 Claude 实测结果等同于 Codex 端到端验收。
- 本次只在隔离测试 profile 安装构建产物，未替换用户日常 DSH profile 中的插件，未合并 main 或推送远端。
