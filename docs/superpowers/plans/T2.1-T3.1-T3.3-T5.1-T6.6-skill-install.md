# T6.6 一键安装通知 Skill

跨任务说明：本功能以页面按钮为核心（T6），同时扩展 Adapter 能力（T2.1/T5.1/T5.2）、新增工具（T3.1）并服务外部通知 Skill 的安装侧（T3.3）。

## 目标

在订阅看板提供一个「安装通知 Skill」按钮，点击后向本机 Claude 开一个**新会话**执行安装提示词，把随包分发的 `external-agent-notification` 通知 Skill 写入 `~/.claude/skills/external-agent-notification/SKILL.md`，让该 Agent 之后能通过通知 Skill 把任务结果 push 回 DSH。

Codex 第一版仍只读（`runPrompt=false`），本功能为其**预留接口**：页面置灰并给出可复制的安装提示词，实际执行安装留待后续版本接入 `codex exec`。

## 范围与边界

- 只做「发消息让 Agent 执行提示词」这一条路径，不直接替 DSH 写 Claude/Codex 的全局技能目录（释放文档已明确：安装脚本不修改 Claude/Codex 全局配置，本功能也不改）。
- 安装提示词由服务端读取随包 `skills/external-agent-notification/SKILL.md` 拼装，内嵌全文并写明目标目录；前端只负责展示、复制和触发。
- Claude 开新会话执行；Codex 返回「后续版本预留」。
- 不判断「安装后是否真的生效」，只报告 `claude -p` 的退出结果；真实安装是否成功由用户在 Agent 侧核对。

## 实现

### Adapter 能力（T2.1/T5.1/T5.2）

- `AdapterCapabilities` 新增 `runPrompt`；`AgentAdapter` 新增 `runPrompt(text, options?)`，`RunPromptResult` 为 `completed / failed / rejected`。
- Claude Adapter：`runPrompt` 调 `claude -p <text> --permission-prompts none --output-format json --add-dir <技能目录>`（不带 `--resume`），等待进程退出，按 `is_error`/退出码判定；超时（默认 5 分钟，`runPromptTimeoutMs`）记为 `failed`。
- Codex Adapter：`capabilities().runPrompt = false`，`runPrompt()` 返回 `rejected`（预留）。

### 技能安装服务（T3.3 安装侧）

`src/services/skill-install.ts`：

- `preview(agent)`：读取 SKILL.md，返回 `{ skill, target_dir, prompt, supported, reason }`，目标目录按 Agent 区分（Claude `~/.claude/skills`，Codex `~/.codex/skills`）。
- `install(agent)`：能力不支持时返回 `{ supported:false, reason }`；否则调 `adapter.runPrompt(prompt, { addDirs:[技能目录] })`。
- 技能源码目录与 home 目录均可注入，便于单元测试。

### RPC / 工具 / 页面

- `relay` 新增 `install_skill_preview`、`install_skill` 两个端点；`index.ts` 接线 `createSkillInstallService({ adapters })`。
- 工具新增 `relay_install_skill`（参数 `agent`）。
- 前端：看板头部新增「安装通知 Skill」按钮；抽屉内选择 Agent、展示目标目录与可复制的提示词，Claude 可「发送安装指令」，Codex 置灰并提示预留。

## 未验证 / 剩余限制

- 未做真实 T7 验收：没有真实跑 `claude -p` 去把 Skill 写进 `~/.claude/skills`。`--add-dir` 与 `--permission-prompts none` 组合下，Claude 非交互执行文件写入是否被放行，需用专用会话实测确认；若不放行，改用 `--allowedTools Write` 或 `--dangerously-skip-permissions`（后者需谨慎）再验。
- Codex 安装执行未实现，仅预留接口与可复制提示词。
- 安装结果只反映 CLI 退出状态，不代表 Skill 已就位。
