## 修复

- `0.1.5` 将检查周期与无活动超时分开。插件默认每分钟直接检查历史，不再唤醒模型执行检查；完成证据优先于活动游标变化，首次识别完成即通知。「立即检查」也不再受无活动超时阻挡。
- 复用持久化订阅及启动对账恢复插件计时器，清理旧 Relay 宿主提醒，不修改其他插件任务。保留旧订阅已配置周期；用户报告的指定订阅通过页面修改为 60 秒。
- `0.1.6` 按通知 `source` 区分投递提示词。`poll` 要求仅整理已有会话信息，说明结果与限制，不按标题或摘要重新执行，不扫描文件、修改文件、启动程序或委派任务。`push` 不套用只汇报约束，由模型结合内容与当前上下文判断。
- 删除原通用指令「请按用户原有要求处理」。外部摘要按 JSON 字符串作为资料插入，保留换行和引号边界。
