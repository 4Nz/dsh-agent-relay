## 用户继续验证

1. 进入已在默认浏览器打开的测试 DSH。首次提示点击“继续”；仅查看设置时可关闭“开始使用”的模型登录引导。
2. 左下角“更多”→“设置”→“TeamRelay”。测试实例保留“本地验收”类型，网络搜索暂分配给 Codex，用于确认持久化；可自行调整。
3. 修改分工并保存，刷新确认恢复。最大并行任务数由系统固定为 4。
4. “Agent 接入”→“登录豆包”，在独立浏览器中扫码或短信登录；回到设置页确认“登录态已保存”，再点击“检测登录状态”。探测有效后才显示已连接。本步骤需要用户认证，尚未执行。
5. “退出登录”只清除测试实例保存的豆包登录态，可用于验证退出行为。

当前没有 TeamRelay 会话模式入口与完整自动调度，不能通过模式选择执行多 Agent 任务。真实模型推理、豆包 HTTP 兼容性、任务派发与汇总均未验收；登录检测不等同于执行成功。

## 重启复现

先结束占用该目录和端口的测试进程，再运行（不要同时运行两份）：


启动将打开带本次认证信息的浏览器入口。认证信息不写入本文。临时目录可能被系统清理，不作为长期安装位置；本轮未替换业务 profile 的插件。
