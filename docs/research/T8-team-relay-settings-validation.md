## 首轮设置页实现（后续豆包调整见文末）

- DSH 原生 `settings.section` 注册 TeamRelay 页面，分为“任务类型”和“Agent 接入”。
- 四默认类型均使用 DSH，支持编辑、新增、删除（保留兜底类型）、单 Agent 或多个 Agent 的分配，以及最大并发配置。
- 页面 RPC、DSH 工具与类型路由共用配置服务。配置保存到插件数据目录的 `team-relay-settings.json`，支持原子替换、版本冲突提示和重启读取；不含凭证。
- Claude 检查本地命令安装，Codex 检查 daemon 握手。无需安装 channel 或通知 Skill，不创建测试会话。
- 豆包显示前置接入说明并禁用选择，WorkBuddy 显示暂未支持。
- 切换设置项保留未保存草稿及类型编辑器；保存期间关闭页面也会结算请求，重开等待同一请求，避免旧 revision 被误恢复。
