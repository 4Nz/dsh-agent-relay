Windows 兼容性边界：Node 的 `homedir()`、`path.join()` 和 `127.0.0.1` 网关访问可复用；Windows 不执行 POSIX `0600` 硬校验，凭据保护依赖当前用户目录 ACL。Windows 下仍需用真实 WorkBuddy 安装验证 token 路径、ACL、会话注册表、JSONL 项目目录和网关端口。

## 已实现边界

- `src/adapters/workbuddy/` 提供 token 读取、网关访问、live/busy 观测、history/replay 读取和本地 JSONL 回退。
- token 每次请求重新读取；读取失败、连接失败或 HTTP 401 时写入不含凭据的 refresh 请求标记，Relay 不替 WorkBuddy 执行刷新。
- 网关历史和 replay 均为 404 且本地 JSONL 不存在或损坏时，返回检查失败；不会伪造 `closed`、`idle` 或 `completed`。
- WorkBuddy 只能用于会话发现、快照、增量和 poll 订阅。`/reply`、`/runs` 和本地会话文件写入都不作为 Relay 投递路径。
- 前置安装页明确显示 WorkBuddy 只读限制；通知 Skill 的安装由 WorkBuddy 会话自行完成，Relay 不通过 `runPrompt` 反向执行安装提示词。
