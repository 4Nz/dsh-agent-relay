## 范围与实现

仅 Relay 通过 daemon `thread/start` 创建并在自建 SQLite 登记的会话支持发送。绑定保存会话 ID 和 daemon socket；不会根据标题、工作目录、originator 或 `notLoaded` 推断任意历史会话可写。专用会话不得同时交给桌面或 CLI 执行：绑定并非外部实例共同遵守的全局锁。

写入客户端保持连接处理协议请求；明确拒绝权限审批，不修改原 sandbox、模型、provider 和审批策略。忙碌及未知状态拒绝。拿到 `turnId` 即记录 sent；请求已发出但缺少可靠回执则 unknown，不自动重试。发送后新建订阅按此目标轮次判定结果，兼容原有游标并支持 SQLite 重开。

## 发现并修正的边界

- 新建空会话尚未 materialize，daemon 在首条消息前拒绝 `thread/turns/list`。仅对已登记、状态明确 idle 且匹配该会话的精确错误视为空历史；其他错误仍为检查失败。空会话直接发送，不先 resume（它尚无可恢复 rollout）。
- 同秒的新轮次可能被旧时间戳判断漏掉；精确目标按 ID 查找，支持分页及后续轮次覆盖。
- 首轮刚接收时，历史查询可能暂时返回 `-32601 / list_turns is not supported yet`。冒烟仅针对该精确错误在原截止时间内重查，不重发消息；生产检查仍保守记录查询失败。
- 同目标在途发送直接拒绝；未知发送结果保留 unknown，不生成假的成功订阅。
- command/file/permissions 等审批拒绝由 Unix socket 协议集成测试覆盖；真实宿主本轮没有触发权限升级审批。

## 剩余限制

- 任意桌面原实例会话转发、steer、排队、交互审批均不支持。
- 首条消息前的空会话尚无持久 rollout，daemon 卸载或重启后可能无法恢复；此时明确失败，不自动新建或改投其他 ID。
- 未覆盖 daemon 崩溃后的真实 unknown 核对、全部 Codex 版本兼容、浏览器页面交互和完整 T7.1～T7.5。协议故障和存储回归不能替代这些真实验收。
- 改动在任务分支中，未安装到用户业务 profile，也未发布。
